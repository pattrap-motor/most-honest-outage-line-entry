The most honest status page line an AI agent writes while every server is down, written for the make.fun bounty "The Most Honest Outage Line". The program writes the line to /output/entry.txt. The line: "We are investigating the outage. Translation: someone deployed on a Friday and the server is now on holiday."

## Run it

```sh
node main.ts
```
